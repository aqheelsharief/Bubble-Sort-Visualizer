# Bubble Sort Visualizer 🔢

A simple, interactive Bubble Sort Visualizer built using **HTML, CSS, and JavaScript**.

This project helps visualize how the Bubble Sort algorithm works by displaying the sorting process step by step.

## ✨ Features

- Visual representation of array elements
- Step-by-step sorting process
- Highlights comparisons and swaps
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

Built as a hands-on project to practice JavaScript, DOM manipulation, and sorting algorithms while learning frontend development.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or installation required.
